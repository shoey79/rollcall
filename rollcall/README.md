# Rollcall

*Who's up, and how are they doing?*

Server monitoring for Home Assistant. Pings your computers on a schedule, checks their services (web apps, SQL, RDP, Plex, UniFi and 80 more presets), and with the optional Windows and Linux agents reports what's going on inside each server: disk space, services, Docker containers, event and journal logs, security events and updates. Any Home Assistant sensor can be a check too, e.g. a UniFi access point's CPU and memory.

Green, amber and red at a glance in a sidebar dashboard, 24-hour uptime, tabs and filters for large estates, phone notifications that open the dashboard, and sensors for every computer and check.

See the **Documentation** tab for setup.
