# Rollcall

*Who's up, and how are they doing?*

Server monitoring for Home Assistant. Pings your devices on a schedule, checks their services (web apps, SQL, RDP, Plex, UniFi and 80 more presets), and reads switches, UPSs, printers, firewalls, VMware and more over SNMP and their own APIs. Optional agents for Windows, Linux, OpenWrt and pfSense/OPNsense report what's going on inside each one: disks, services, backups, logs, security events, updates, known vulnerabilities and WordPress sites. Any Home Assistant sensor can be a check too.

Green, amber and red at a glance in a sidebar dashboard, 24-hour uptime, tabs, search and notes for large estates, phone and email alerts, and sensors for every device and check.

See the **Documentation** tab for setup.
