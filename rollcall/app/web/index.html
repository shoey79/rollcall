Details

Agents

One agent for Windows and one for Linux. Each works out what the server runs and reports disk space, storage health, services, logs, security and updates. Agents send reports; they never take instructions, apart from updates and messages that you turn on.

Database

Rollcall's history, readings and syslog messages, and everything else in its data folder on Home Assistant's disk.

Messages

A short message on the screens of agent devices you include, under the heading Message from the Rollcall Administrator. It's shown at each device's next report, within about 5 minutes.

Find software

Which devices with an agent have a program installed, and which version. Searches program names and publishers.

Export / import
Move everything to another install of this add-on, e.g. when switching to the GitHub version.

    

      

        
Export

        
Downloads one file with your devices and their checks, tabs, pauses, agent approvals, ignores and disk thresholds,
          each agent's last report, uptime history, and the Configuration-tab settings.

        
Keep the file safe: it contains the agent enrolment key and could be used to restore your monitoring elsewhere.

         
      

      

        
Import

        
Replaces everything on this install with the export, then restarts the add-on. What's here now is kept in a
          before_import_… folder in the add-on's data folder, just in case.

        
Agents carry on reporting without being reinstalled, as long as they can reach this install on the same address and port.

Create a key in Jellyfin under Dashboard, API Keys. Rollcall reads the version, a pending restart, updates, failed scheduled tasks (amber, no alert) and how many streams are playing; it goes red, with an alert, if Jellyfin stops answering. The key is only ever sent to this address, and isn't shown again; moving the address to another machine means entering the key again (switching to https, the port or its name is fine). Leave the address blank for port 8096 on this device.

        

        

          

            
            
          

          
To find the token, open any film or episode in Plex Web, choose Get Info, then View XML: it's at the very end of the address of the tab that opens (…&X-Plex-Token=token), not in the page itself. Or, on the Plex server, it's PlexOnlineToken in Plex's Preferences.xml (Linux, Docker) or, on Windows, in the registry under HKEY_CURRENT_USER\Software\Plex, Inc.\Plex Media Server. Rollcall reads the version, an update (amber, no alert) and what's playing, by whom; it goes red, with an alert, if Plex stops answering. The token is only ever sent to this address, and isn't shown again; moving the address to another machine means entering it again (switching to https, the port or its name is fine). Leave the address blank for port 32400 on this device; if Plex only accepts secure connections, HTTPS is used.
