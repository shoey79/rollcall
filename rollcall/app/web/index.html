Details

Agents

One agent for Windows and one for Linux. Each works out what the server runs and reports disk space, storage health, services, logs, security and updates. Agents only send reports; they never take instructions.

Find software

Which computers with an agent have a program installed, and which version. Searches program names and publishers.

Discover devices

Scan your network for devices that aren't in Rollcall yet. Each one gets a guess at what it is and which checks would suit it; Add fills in the form for you.

Export / import

Move everything to another install of this add-on, e.g. when switching to the GitHub version.

Export

Downloads one file with your computers and their checks, tabs, pauses, agent approvals, ignores and disk thresholds, each agent's last report, uptime history, and the Configuration-tab settings.

Keep the file safe: it contains the agent enrolment key and could be used to restore your monitoring elsewhere.

Import

Replaces everything on this install with the export, then restarts the add-on. What's here now is kept in a before_import_… folder in the add-on's data folder, just in case.

Agents carry on reporting without being reinstalled, as long as they can reach this install on the same address and port.

Other addresses

For devices with more than one network address, e.g. a firewall's WAN and internal IPs. Each one is pinged while the main address answers, and goes red if it stops; add ports to check them there too. Syslog from any of these addresses is matched to this device.

Custom checks

A port: tcp:5985 · a web page on this computer: https:443/owa · a full URL: https://mail.example.local/owa
Give it a name with Name=, e.g. Reporting=tcp:50123
Certificate expiry: cert:443, SMTP=cert:25 (mail ports use STARTTLS), or on another name or address cert:mail.example.com:443
A Home Assistant sensor: CPU=ha:sensor.office_ap_cpu_utilization>90 goes amber, then red, while the condition is true (> < = !=). Without a condition it only needs to be available.

Monitoring schedule

Times are in Home Assistant's time zone. A window can run past midnight, e.g. 22:00 to 06:00 (it belongs to the day it starts).
